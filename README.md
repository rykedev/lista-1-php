# Resumo dos Códigos em PHP

Este projeto consiste em uma série de exercícios práticos de lógica de programação utilizando PHP. Abaixo está o resumo do que cada script faz.

---

## 📋 Resumo Funcional dos Códigos

* **Atividade 1 (Sistema de Aprovação):** Recebe a média e o total de faltas de um aluno. Utiliza o operador lógico `&&` para validar se a média é maior/igual a 6,0 **E** as faltas são menores/iguais a 15, exibindo na tela se o aluno foi aprovado ou reprovado.
* **Atividade 2 (Tabuada com `for`):** Define um número base e utiliza um laço de repetição `for` para iterar de 1 a 10. Em cada volta do laço, realiza a multiplicação e exibe o resultado formatado.
* **Atividade 3 (Processamento de Array de Notas):** Armazena 5 notas em um vetor (array), percorre os elementos para calcular a soma e identificar dinamicamente a maior e a menor nota. Ao final, calcula e exibe a média geral da turma.
* **Atividade 4 (Calculadora e Classificador de IMC):** Define a função `calcularIMC($peso, $altura)` que realiza o cálculo matemático do IMC e utiliza estruturas condicionais `if / elseif / else` para retornar a classificação correspondente (Abaixo do peso, Peso normal, Sobrepeso ou Obesidade).
